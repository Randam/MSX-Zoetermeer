# MSX Zoetermeer

Nederlandstalige website van de MSX-gebruikersgroep in Zoetermeer. De website staat op [msxzoetermeer.nl](https://msxzoetermeer.nl/), met DNS via Cloudflare. GitHub Pages publiceert de map `docs/` vanaf `main`. Voor lokaal gebruik is geen build of installatie nodig.

```sh
python3 -m http.server 8765 --directory docs
```

## Volgende editie

De volgende editie is op zaterdag 30 januari 2027 van 10:00 tot 16:00 uur in Wijkcentrum De Vlieger.

## Aanmeldingen en updates in Brevo

De aanmeldknoppen in `docs/index.html` verwijzen naar twee openbare, gehoste Brevo-formulieren. Beide gebruiken dubbele bevestiging per e-mail.

- **MSX-updates** is de lijst voor uitnodigingen voor volgende bijeenkomsten. Selecteer deze lijst als ontvangers van nieuwsbriefcampagnes en laat de afmeldlink in iedere nieuwsbrief staan.
- **Deelnemers 30 januari 2027** is de lijst voor deze editie. In het formulier staan optioneel voornaam, tafelplek, praatje en onderwerp naast het verplichte e-mailadres. Toon de velden **Tafelplek**, **Praatje** en **Onderwerp** als kolommen bij de deelnemers of selecteer ze voor een [CSV-export](https://help.brevo.com/hc/en-us/articles/5310065850642-Export-your-contacts-from-Brevo). Beoordeel aanvragen voor een tafelplek of praatje apart.
- Maak voor een nieuwe editie een deelnemerslijst en een kopie van het deelnemersformulier met de nieuwe datum. Werk vervolgens de datum en formulierlink op de site bij. Exporteer de benodigde gegevens van de vorige editie voordat je dezelfde contactvelden hergebruikt.
